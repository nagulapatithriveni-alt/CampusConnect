# CampusConnect

CampusConnect is a full-stack job portal designed to connect students with job opportunities.

## Features

- Student registration and login
- Browse available jobs
- View job details
- Apply for jobs
- Resume upload
- Resume download
- View submitted applications
- Application status tracking
- Student notifications
- Clear notifications
- Job management through backend APIs

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs

### Database
- MySQL

### Security
- BCrypt password hashing
